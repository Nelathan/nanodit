2026-11-05. SPEC §3 stated width 512 and depth 12 while every run since `128_d1024x16_5ep` used 1024 × 16
(293.8M parameters, FACTS). Daniel: "Update spec, the big one trains well. Too big is wasteful because compute is
limited and data too. Idk if 768 would be better but 512 was too small." Concepts emerged at d768 and d1024 and not at
d512 (PLAN G5), and `128_d1024x16_swpin_5ep` is the best run (FACTS).

SPEC §3 states width 1024, depth 16, 16 heads of 64; §5 the projections into 1024. `DiT` takes depth and width without
defaults. Whether 768 would do as well is untested.
