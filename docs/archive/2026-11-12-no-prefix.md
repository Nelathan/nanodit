# The captions are encoded with no prefix; the token states drop `<bos>` and `<eos>`

2026-11-12. Closes the caption-prefix question.

Decided: EmbeddingGemma 2 encodes each caption as it is, with no task or document prefix, for training and inference
(SPEC §1). The pooled embedding averages every token, `<bos>` and `<eos>` included. The token states for cross
attention drop `<bos>` and `<eos>`; the null prompt's two learned tokens start as the empty caption's `<bos>` and
`<eos>` states, the only ones it has (SPEC §5). Every stored embedding and token sequence is re-encoded from its
caption (`scripts/reencode_text.py`).

Reasons: on caption-to-image retrieval over 1000 eval images, no prefix ranks the caption's own image first for 94.4 %,
the card's retrieval query `task: search result | query: ` for 93.2 %, level at a standard error of about
0.75 points each, and the document prefix the data carried for 90.5 % (FACTS, caption prefix). The card's query prefix is
for a caption searching documents; it was not wanted over the simpler form, which measured as well. `<bos>` and
`<eos>` carry nothing of the caption, so cross attention gains nothing from them. A paired training arm was not
wanted: the re-encode is text only, and no long run rests on the old encoding.
